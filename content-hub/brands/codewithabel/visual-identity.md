# Visual identity: codewithabel, Direction A "dev log" (stills approved? NOT YET)
Concept: a developer's commit log. IDE night colours, monospace-forward, a "DAY NN" counter, diff semantics for colour. Distinct from Disojo (calm editorial ink/cream) and trading (paper journal).
- **Palette (each colour means something):** bg `#0B0D12`, surface `#12161F`, ink `#D9E0EC`, muted `#7C8799`, **lime `#B8F34B` = shipped / the point**, amber `#FFB547` = in progress / the note, red `#FF5C5C` = broken. Max 5 hues.
- **Type:** Space Grotesk 700 for statements (tight -0.045em), JetBrains Mono 500-800 for tags, code, captions and the status bar.
- **Motifs:** `DAY 07` tag (outlined lime), breadcrumb path (`disojo / reel-studio / edit_reel.py`), line-number gutter, faint grid with a lime glow, VS Code-style status bar (`main  0 errors`), real code blocks with one highlighted line and an amber annotation arrow.
- **Reels:** panel on top = grid + glow + big statement with a lime block highlight on the key words; captions in a terminal-like box (10 px radius, hairline lime edge) with a lime block highlight and a blinking caret; screen recordings fill the panel for builds (needs a `screen` panel type in the engine: NOT BUILT).
- **Carousels:** code-first slides (real snippets only), cover = statement + sub in `//` comments.
- **Motion:** faster, snappier than Disojo (Energetic-leaning): quick 100-200 ms entrances, typing/cursor motion, line-by-line reveals. Springs damping still >= .72.
- **Sound:** soft keyboard/click ticks from the CC0 kit (tick, click), minimal whoosh.
- **Never:** matrix rain, neon gradients, hacker clichés, fake terminal output presented as real, emoji.
