# Copy rules: hooks, scripts, captions (merged from going-viral, viral-hook-writer, reel-scripter, no-ai-slop, brand-voice)

Read the brand's `voice.md` first (trading has one). If a brand has no voice file, ask for 3-5 real samples; do not imitate generic creators.

## Hooks (first ~1.5s)
1. Pick ONE goal per reel: save / share / follow / lead. It decides the emotion and the CTA.
2. Open a gap, not a fact. "The one habit that..." beats "Here are some tips".
3. Frame 0 is already moving (the edit adds a slow push). On-screen hook text lands at ~0.15s; the emphasised phrase wipes in at ~1.2s (the claim beat). Must read on mute.
4. Under 12 spoken words. Write 10, rank 3 to test. Film 2-3 variants of the first line over the same body (his existing A/B/C habit).
5. Tease, never lie: any loop opened must be paid off before the end. Any "comment WORD" must actually deliver.
6. Rotate angle each post: contrarian / result-first / mistake / numbered / POV. Do not default to listicles.

## Script
- 30-45s max, one idea, spoken language. Hook -> claim -> 3 beats -> payoff -> ONE CTA.
- Re-hook at the dips (~4s, 9s, 15s) with a plain line, not a gimmick.
- Every line should be something he would actually say. Read it aloud test.

## Anti-slop (no-ai-slop skill)
- Cut: delve/leverage/streamline/game changer/"here's the thing"/"nobody tells you"/"the truth is" as filler (his real "the truth is simple" is allowed because it is his).
- No fake-profound closers, no summary recaps, no stacked fragments ("X. Y. Z."), no rhetorical "what if I told you".
- Contrast pattern ("not X, it's Y"): max once per script.
- No em dashes in captions or short copy. No emoji headings. Concrete beats abstract.
- Never invent stats, results, quotes, testimonials, client names. If a number is needed and not given, ask or leave it out.

## Brand guards
- abelkapoor-trading: education only. No advice, recommendations, signals, entries/targets, return or win-rate claims, no unsourced stats, no selling/referrals/app/course (no selling for 6+ months), disclaimer on every post, nothing linking to the Disojo world. Process, discipline, mistakes. Flag anything borderline for SEBI and ask.
- disojo: no client names/figures without client OK. Postcards +42% is client-reported. Pricing is never shown.
- personal: only facts he confirmed.

## Output format for a reel package
1. Goal + one-line angle. 2. 10 hooks (3 ranked, 3-5 word on-screen version each). 3. Script with beats and on-screen text. 4. Shot notes (what to film, how long). 5. Caption (keyword/CTA in first line) + hashtags. 6. Honesty check: list any claim that needs his confirmation.

## On-screen hook layout (learned 2026-10-13)
Hook lines must be short: max ~18 characters per line, 2-3 lines, 104px type. Longer lines get auto-shrunk and look weak. Break the copy yourself with `\n`, e.g. "After a loss,\nyour brain finds\n*perfect setups.*"

## Tier-1 language gate (decided 2026-10-14)
Audience is US/UK/Canada/Europe. English only, US/UK spelling, $/£/€ examples, no Hinglish, no India-specific references (WhatsApp, GST, UPI, rupees, Indian regulators). Bombay may be mentioned honestly for Disojo/codewithabel. Hot takes are opinions about practices, never people, and need his approval. Trading: education only, no return claims, no selling, disclaimer on every piece.
