# Client site (Disojo starter)

1. Edit `src/brand.config.js`, `src/data/products.js`, `src/data/quiz.js`.
2. Put real assets in `public/` (see the disojo-site-starter skill for the list and sizes).
3. `npm install && npm run dev`
4. `npm run build` (also syncs SEO meta from the config), then `node scripts/smoke.cjs <url> <outdir>`.

Placeholders (`public/images/*`, `public/hero-frames/frame-001.jpg`, `public/og.jpg`) are generated by `npm run placeholders`: never ship them.
