# @codewithabel copywriting (build in public, developer brand)

Read first: `content-hub/brands/codewithabel/` (brand.md, strategy, voice.md, hook-bank.md, story bank) and `references/research-2026-10-18.md`. Full report: `content-hub/reports/codewithabel-content-report-2026-10-18.md`.

## The one-line frame
**A founder who runs a real software studio and builds its tools with AI, showing the thing working first and the mess honestly.** Not a tutorial channel, not a hype channel. The proof is that the builds are real and used by a business.

## What the research proved
1. **Tangible demo beats abstract code.** NFC stickers in hand (215K-1M), Oreos as data structures (2.9M). Frame 1 shows the thing; spoken line 1 is show-and-tell ("So this is the reel my editor made").
2. **Series with parts compound.** "Vibe coding things in the real world, Part 1-3": 52K, 1M, 766K.
3. **Tool tests and tool news spike** (Grok vs Opus 6.4M; "10+ free AI coders by Google" 999K) but are a treadmill: use for reach, not identity.
4. **Stack recipe + keyword freebie** drives comments ("Claude Code + insForge + Stripe... comment 'guide'" 34K likes / 8.6K comments).
5. **Plain "Day N" flops** (27-120 likes) unless the day has a specific tension or result ("Fifty doors. Almost zero owners.").
6. **Career/identity anxiety** reaches widest ("my biggest college regret" 5.4M, "degrees safe from AI" 757K).
7. **A consistent visual template** makes you recognisable (Nick's covers, Jack's desk). Ours: the locked codewithabel identity (cobalt #2338FF, acid #D9FF3F, ink, Bricolage, giant outlined DAY number).

## Signature series (build these; all true material)
- **"I'm building my own CapCut with AI"** (the reel engine: v1 to v9, the gray HDR bug, the twitching bug, Remotion). Part N per real milestone.
- **"Claude Code runs my studio"**: skills, automations and tools the studio actually uses (20+ skills, the reel editor, client portal, carousels).
- **"AI got this wrong"**: real failures and how they were caught (corrupt frames, wrong sign in stabilisation, overflowing captions).
- **"Tested so you don't have to"**: tool/model tests on a REAL task from the studio (not toy prompts), with an honest verdict.
- **"From client brief to live site"**: client builds only with the client's OK (Postcards 3D rebuild, Ascender), numbers only from the verified list.

## Script shapes (A 25-45 s)
- **Demo**: result on screen 0-2 s -> "here's how it works" in 3 beats -> the catch (what's still bad) -> "Part N tomorrow" or "follow for Part N".
- **Bug autopsy**: symptom (show it) -> wrong theory -> how it was measured -> the fix -> lesson in one line.
- **Test**: the real task -> tool A result -> tool B result -> honest verdict with a caveat.
- **List**: N items, one per 2-3 s, each with a 4-word reason.
- **Take**: one line -> one example from his work -> one line back.
Voice: plain, specific, dry humour; "built with Claude Code" disclosed; no "game-changer", no fake metrics; numbers real or labelled illustrative.

## Captions, CTAs, platform copy
- IG/TikTok caption: one honest sentence + "Part N tomorrow." or "Built with Claude Code." + 2-3 hashtags (#buildinpublic #claudecode #indiedev).
- X: the hook as the first line, then 3-6 short lines of what happened, a screenshot or clip. LinkedIn: first line hook, short paragraphs, the lesson, no outbound link in the body.
- CTA ladder: follow for Part N -> keyword freebie (month 2+) -> "we build this for businesses" (Disojo, link in bio) max 1 in 10.
- Bio (draft): "Building Disojo's tools with AI, in public | disojostudio.com".

## Truth filter (reject if any fails)
1. Only real builds, real bugs, real numbers (or labelled illustrative). Story bank in brand.md is the source.
2. Disclose AI assistance. Never imply hand-written code that wasn't.
3. No secrets, keys, client data or private repo contents on screen (blur). Client names only with OK.
4. No trading content, ever. No India-specific references (Bombay as honest context is fine).
5. Hot takes are his opinions: get his approval per take.

## QA gate
Frame 1 shows a result? Hook <= 10 words with a concrete noun? Fits a series or a formula? True (source in story bank)? Disclosure present? No secrets visible? Then show with formula numbers.
