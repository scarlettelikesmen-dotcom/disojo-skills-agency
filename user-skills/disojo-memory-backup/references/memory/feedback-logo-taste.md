For logos, Tejjomay rejects generic growth symbols outright (the ascending-bars "Rise" direction for Ascender was "disgusting") and wants creative use of the client's own craft vocabulary (for a video editor: playhead, cuts, in/out brackets, keyframes, captions), with OH Architecture-level restraint and one clean grotesque.
**Why:** a branding studio's own work must look designed, not AI or stock.
**How to apply:** follow ~/.claude/skills/disojo-logo-design; show 3 different directions in the in-app browser, honest about the weakest. Related: [[feedback-unique-design-per-client]], [[project-ascender-media-rebuild]].
