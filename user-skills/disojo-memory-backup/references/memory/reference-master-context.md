`~/.claude/CLAUDE.md` is loaded at the start of every Claude Code session in every project: business, goals, skill index, working rules, environment notes.
`~/.claude/master-context-for-claude-ai.md` is a short pasteable version for claude.ai preferences or a Project's instructions (not synced automatically).
When business facts, goals or working preferences change, update CLAUDE.md first; keep long procedures in skills and history in memory. See [[feedback-working-style]], [[disojo-business]].
