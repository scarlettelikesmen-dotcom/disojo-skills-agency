On Print Elements (2026-10-13) I read only the premium-site-method and design skills, skipped disojo-client-playbook, intake, archetypes, starter and motion-recipes, and shipped a clean dark static site on stock mockups. Tejjomay: "disgusting", "who the fuck do you think you are", and made me read every skill in the repo.

**Why:** the playbook says the first demo comes from REAL assets; with nothing usable, stop and request photos. Mochi & Midori and Postcards are built on real product photography and film with cinematic scroll; a competent template is not the bar. THOUGHTS.md: one real idea, real material beats invented polish, check "does this look expensive".
**How to apply:** when a new client or rebuild comes up, FIRST read disojo-client-playbook, then follow its steps in order (asset request, inventory, archetype stated in one line, starter for plumbing only). If assets are missing, say so and ask; do not ship placeholder-based demos. When Tejjomay says "read the skills", read the whole Disojo set plus design skills, then report what was read and what was not. Do not claim a skill was read if only its description was.
