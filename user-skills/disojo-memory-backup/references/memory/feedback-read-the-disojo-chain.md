Tejjomay expects the full Disojo skills chain to be read and followed before any build, not a shortcut that ships a clean but generic site.

**Why:** the playbook says the first demo comes from REAL assets; with nothing usable, stop and request photos. A competent template is not the bar. One real idea, real material beats invented polish; check "does this look expensive".
**How to apply:** when a new client or rebuild comes up, FIRST read `disojo-client-playbook` (and for the premium tier `high-ticket-flagship-3d`), then follow its steps in order (asset request, inventory, archetype stated in one line, starter for plumbing only). If assets are missing, say so and ask; do not ship placeholder-based demos. When Tejjomay says "read the skills", read the whole Disojo set plus design skills, then report what was read and what was not. Do not claim a skill was read if only its description was.
