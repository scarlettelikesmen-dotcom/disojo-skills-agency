Researched 2026-10-08 by downloading ciaoenergy.com / palmo.co.in assets: both load the byte-identical 160 KB `can.glb` (3,918 vertices, no baked label), Ciao swaps six flat AVIF label textures. The kit (`~/.claude/skills/disojo-packaged-product-3d/kit`) rebuilds that idea: can/jar/bottle/box templates, ProductStage with label swap + scroll rotation, GLB export, smoke test (7/7 pass headless). Not yet used on a client; real-phone untested. Food routes ranked in `references/food-and-other-routes.md`; the AI image-to-3D and photogrammetry test protocols there are written but NOT yet run.
