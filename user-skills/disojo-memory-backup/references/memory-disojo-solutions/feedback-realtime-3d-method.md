For any live 3D product, follow skill `disojo-realtime-3d-product` and read its post-mortem first.
**Why:** VÆL failed three times on 2026-11-03 (rendered stills, then a flat untextured GLB, then my "needs a 3D artist" detour) before the reference-sheet + baked-maps + raking-light method landed ("soooooo much better"). Tejjo's stance: nothing is impossible, figure it out, no hiring.
**How to apply:** reference sheet first, design every surface, bake colour/rough/normal/AO, light from the side, real font from the first screenshot, side by side before showing. Related: [[feedback-gates-are-not-quality]], [[project-vael-site]].
