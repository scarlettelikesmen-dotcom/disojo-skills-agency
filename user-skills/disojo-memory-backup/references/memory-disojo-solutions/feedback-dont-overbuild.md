After Tejjo said "Keep going" on the Marathon home page, I built 8 project pages, the projects index, completed projects, contact and a sign-off list without checking back. Tejjo: "you dont need to build so much" (it was also a test, not a real client; see [[project-marathon]]).

**Why:** "keep going" is not a licence to build the whole site in one run. Hours spent before Tejjo looks are wasted if the direction or the job itself changes.

**How to apply:** after an approval, build the next one piece (one page or one template), show it, and wait. State the remaining plan in a line instead of executing all of it.
