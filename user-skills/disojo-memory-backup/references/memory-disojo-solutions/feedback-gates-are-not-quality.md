- Before calling any flagship or premium site done, put it side by side with the nine references, screen by screen, and score it with 05-exceed-standard.md (sections A and C). If it doesn't clearly beat them, it isn't done, and I say so instead of sending it.

- Study the references hands-on before building, offer concepts in words, and get Tejjo's pick.
- Verify every link I send by its page title.
