Our builds looked "all zoomed in, no beauty" (Tejjo 2026-11-23). Measured vs 216 TFTL screens: ours twice as loud, type 2.4x bigger, 3x the text, full contrast, loud flat colour. Tejjo on the side-by-side boards: "this is actually really good".

**Why:** we design in code and code pulls to defaults (heading, paragraph, button) set at maximum; TFTL composes screens as pictures first.

**How to apply:** websites skill step 5: 6-8 still frames labelled quiet/photo/event (one event per page), wide graded pictures, type with range not size, tinted grounds, then `beauty_pixels.py --check` and a board beside TFTL frames before any motion. Keep our clarity and readability; that is how we beat them. Method: `disojo-site-system/references/beauty.md`. Related: [[feedback-moments-per-client]], [[feedback-gates-are-not-quality]].
