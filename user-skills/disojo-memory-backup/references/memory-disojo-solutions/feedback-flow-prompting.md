Tejjo, 2026-11-16, after my first Flow tests (generic desk, notched phone) came out like stock: they use Flow a lot, Nano Banana Pro is really good, the results depend on very detailed, researched prompting, and they expect me to be excellent at it.

**Why:** short mood prompts gave average stock images; the tool was not the problem.
**How to apply:** before generating, write each prompt as a full brief (subject and exact materials, composition and framing, camera and lens, light direction and quality, colour values, surface, what is excluded), use reference images (our real chart renders, app screens, the logo master) as ingredients, and explain in one line what each image is for on the site before running it. Defaults in Flow: Nano Banana Pro, x4. Related: [[feedback-downloads-computer-access]], [[project-level-trading-playbook]].
