On Level (2026-11-17) I built the site with amber lines and a dark ground. Amber was only proposed, and Tejjo had assumed light all along. "who the fuck allowed you to use those disgusting yellow lines" / "i thought it was hella clear that the product and the site should be light".

**Why:** a proposal shown inside a build reads as a decision I made for them, and it wastes the first look on things they never chose.

**How to apply:** before the first screen, list the basics the build depends on (ground light or dark, accent or none, type) and confirm each in one line. If a choice is not picked, build without it (no accent) rather than with my pick. When feedback is ambiguous ("looking like paper"), ask which part: the idea or the colour. Related: [[feedback-idea-before-pixels]], [[feedback-own-verdict-before-showing]].
