Tejjo said on 2026-11-11, during the CTESCOA first screens: "huge rectangular CTA buttons like with the text in between and a huge rectangle button. I hate it."

**Why:** a solid block of colour with a centred label looks like the default for every site. It is the same complaint as [[feedback-multipage-no-basic-ctas]].

**How to apply:** do not fill a whole cell, strip end or box with the accent and centre the label in it. Make the action a typographic element that comes from the idea, such as a label with a leader line and arrow on a drawing sheet. It still needs the roll motion from [[feedback-text-button-roll]]. If a filled button seems truly needed, keep it small and ask first.
