# Identity checklist (answer in one line each before writing UI; write it into PLAN.md)
1. Concept: ONE idea from the brand's name or its product truth, stated without naming a colour or effect, approved by Tejjomay in words before any UI. Build the page out of that idea at full commitment; do not decorate a normal page with craft props (Ascender v1's editing-suite costume was rejected). Not: "dark SaaS", not the client's app UI enlarged (Mentable v1).
2. Palette: 3 neutrals + ONE accent; contrast checked (>= 4.5:1 text, buttons dark-on-accent).
3. Type: display + body + mono for data. No Inter/Roboto/Arial. No random serif emphasis.
4. Nav: small and consistent; its form follows the concept. A plain wordmark + inline links + one pill CTA is fine when executed with restraint (OH does exactly that). Do not invent an unusual nav just to be different.
5. Scroll logic: what moves with scroll and why (Ascender: global timecode + playhead; pinned tracks; sideways chat wall).
6. Surfaces: one radius rule per page. Prefer hairlines, space and full-bleed imagery over cards; the references use almost no cards. No double-bezel card stacks as a default.
7. Proof: what real proof exists? If none can be shown, say so on the page and use what is real.
8. System: one type scale (few sizes, big jumps), one label style, one grid, repeated across the page. Variety comes from scale and pacing, not from a new layout family per section. Max 2 image+text splits in a row still applies.
9. Footer: whatever the concept needs. A giant wordmark is fine if it belongs to the identity (OH, Supersolid do it); a live, true detail (local time, open/closed) earns its place.
10. Motion budget: every animation answers "what does it communicate?"; custom cubic-beziers; transform/opacity only; hover gated by `(hover: hover)`.
