# QA before showing a client a 3D pack

- [ ] Label artwork is the client's print file; every letter checked against the real pack (cap, lid, claims, barcode area).
- [ ] The middle of the artwork is on the front; the seam is at the back; text is not mirrored.
- [ ] Pack proportions match the real product (measure height:diameter).
- [ ] Reflections look like the material (aluminium, glass, matte); no blown highlights on the label colours (check the brand colour against the flat art).
- [ ] Flavour swap: spin plays, artwork changes at the halfway point, no flash of the old label.
- [ ] Scroll rotation is tied to scroll with nothing happening before it should (see the Mochi & Midori hero lesson).
- [ ] Phone: low mode works, fallback image shown when WebGL is off, reduced-motion respected, no horizontal overflow.
- [ ] Weight: model <= 200 KB, each label <= 250 KB, HDR 1k <= 1.5 MB, three.js chunk lazy-loaded.
- [ ] Lighthouse mobile checked on the deployed page; real iPhone tested (not done for the kit yet).
- [ ] LICENCES.md filled; AI use disclosed.
