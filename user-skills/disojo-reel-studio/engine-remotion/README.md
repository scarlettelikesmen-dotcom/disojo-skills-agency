# Remotion engine (v5-v7 pilot, 2026-10-17). Source of truth is this folder; the working copy with node_modules is `content-hub/remotion-lab/` (copy this folder there, `npm i remotion @remotion/cli @remotion/transitions @remotion/shapes @remotion/motion-blur @remotion/media-utils @remotion/three three @react-three/fiber react react-dom typescript @types/react @types/react-dom @types/three`).
Pipeline per reel: (1) `engine/tools/edit_reel.py CLIP --transcript-only`, write a plan json (keep/fix/emphasis), (2) `engine/tools/make_base.py CLIP --out edits/NAME --plan plan.json` -> `edits/NAME/base.mp4` (cut, HDR->SDR, grade, voice clean, loudnorm, NO overlays) + base.json, (3) build `src/spec.json` from `edits/NAME/timeline.json` (captions) + panels list + segments (see how the 2198 pilot was made), copy base.mp4 into `public/`, generate `public/sfx.wav` with `edit_reel.make_sfx` from the spec events, (4) `npx remotion render src/index.ts Reel out/reel.mp4 --gl=angle`. ~2.5 min per 27 s reel. Config: local Chrome, angle GL (WebGL works headless), concurrency 2.
Files: `Reel.tsx` (layout spring, camera, layers), `Captions.tsx` (boxed captions + highlighter), `Panels.tsx` (flat typographic panels + lower third), `Scene3D.tsx` (nine persistent 3D modules re-forming per panel: messy, clean wall, balance, ring, staircase; look-dev: ACES, RoomEnvironment light, key light + shadow, clearcoat ink, matte cream), `theme.ts` (tokens, spring presets, `sp`), `spec.json`.
Rules learned from Tejjomay's notes: no stacked zoom pulses on jump cuts and no blur kicks (they read as twitching); no dot grids/radial glows/eyebrow caps/italic accents/avatar chips (AI tells); flat type-only panels are "too raw": use one persistent hero object + graded footage; captions are still the generic dark pill (open).
Not yet done: b-roll, scene transitions, code/terminal/screen-recording components (codewithabel), per-account themes (Disojo ink/cream only), trading look, captions redesign, phone test.
