## Shared easing and timing (CSS variables seen across the Webflow sites)
`--animation-primary: cubic-bezier(0.83, 0, 0.17, 1)`, `--animation-secondary: cubic-bezier(0.16, 1, 0.3, 1)`. Common hover ease `cubic-bezier(0.625, 0.05, 0, 1)`. Durations 0.2 / 0.3 / 0.5 / 0.6 / 0.65 / 0.75 s.

## Phone-width check (343 px)
Seven sites were checked at 343 px (OH, Mammoth, Supersolid, SLIK, HISS, Backhouse, Squiggle): none had horizontal overflow (page width equalled window width). Ciao and Palmo were not opened at phone width. First-screen visibility was the weak point on four of the seven.
