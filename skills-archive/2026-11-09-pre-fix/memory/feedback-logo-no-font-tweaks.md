2026-10-21: three Disojo directions (toggle o, patched ring o, lifted d stem), each a stock lowercase font with one tweaked letter, got "what the fuck is this... disgusting" after Tejjo had shown Bloom, Nonstop, ALCHE and Monolog (heavy custom caps: a looped e, a hollow square O).

**Why:** a font plus one gimmick is exactly the "disojo in a pretty font" he asked to get away from. The ideas were literal UI clip-art (a switch, a chart, a block). The skill's "one grotesque, one custom detail, OH restraint" rule produced it. I checked whether the sketches were readable, not whether anyone would want them.

**How to apply:** for logos he references, construct the letters and marks (custom drawn caps, geometry built from primitives, several glyphs redrawn). Explore wide first (20+ rough marks in a grid, Bloom-style), let him circle some, then refine. Before showing, put mine next to his references at the same size; if it looks weaker, don't show it. Say plainly that hand lettering (Nonstop style) is beyond code drawing. Related: [[feedback-logo-taste]], [[project-disojo-logo-redo]]
